Create the API-key Secret before installation:

  kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.existingSecret }} --from-file=api-key=./apikey.txt

Inspect reconciliation logs:

  kubectl -n {{ .Release.Namespace }} logs deployment/{{ include "scheduled-woop.fullname" . }} -f

Check health and metrics:

  kubectl -n {{ .Release.Namespace }} port-forward service/{{ include "scheduled-woop.fullname" . }} 8080:{{ .Values.observability.port }}
  curl http://127.0.0.1:8080/healthz
  curl http://127.0.0.1:8080/metrics
